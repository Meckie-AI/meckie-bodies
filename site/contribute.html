A body is one folder. CI enforces the rest, so the fastest way to learn the standard is to run it on your branch.

01

The shape of a pack

bodies/<slug>/
  <Name> Design Brief.dc.html     the full brief, sections 01-06
  <Name> Viewer.html              three.js viewer
  <Name> Print Parts.html         live CSG generator — the geometric source of truth
  stl/<slug>-<part>-x<qty>.stl    print files, quantity in the name
  parts-list.csv                  part,qty,where,link,notes
  firmware/hangar_bay_<slug>.yaml the body manifest — the one authored copy
  hangar-bay/<slug>.template.yaml generated from it
  generated/manifest.json         generated — what Meckie OS consumes
  generated/build.json            generated
  README.txt                      maker instructions
  LICENSE.txt                     CERN-OHL-S-2.0 + MIT
Three of those are generated. Edit the manifest, then npm run sync && npm run emit, and commit the result. CI fails if the committed output does not match a fresh run.
02

The rules CI enforces

1. No glue, ever

Everything screws into heat-set inserts or snaps together. Press-fits only where a screw or clamp retains them. CI reads the 05c assembly table: every joint's method must come from a mechanical vocabulary, and an adhesive word may appear in a joint description only in a sentence that rules it out.

2. Anything that drives senses ahead and below

A body with drives: true declares a peripheral with role: obstacle and at least two with role: drop_off, and every drop-off sensor must be wired into the edge reflex. A fixed base says why the rule does not apply rather than leaving the exemption implicit. Enforced by role, not by name — the names varied between packs and the rule silently passed bodies that only looked compliant.

3. The safety reflex

On heartbeat loss (~500 ms), low battery or servo over-temperature the body stops, brakes, waits about 2 s, moves slowly to a safe rest pose, lowers torque and shows a lost-connection face. It resumes only on a fresh command. And the calibration wizard ends in a required safety_test — the one check that proves it parks itself when Central goes away.

4. Pins are unique per host MCU

Partitioned by host, because a two-board body has two independent GPIO spaces and merging them invents collisions that do not exist. One pin may carry two signals only where shared_pins declares it, names every signal on it, and says how it is shared.

5. Fabrication

Fits a 256 × 256 mm bed. PETG shells, CF-nylon structure, TPU bumpers and tyres. Bearings at every pivot, metal servo horns, hidden fasteners. Insert bores: M2 Ø3.2 · M2.5 Ø3.6 · M3 Ø4.0 · M4 Ø5.6 · M5 Ø6.4. Supplier links stay plain — no affiliate tags, and prefer a search URL to a specific listing, because listings rot and searches do not.

03

Submitting

git checkout -b my-body
# add bodies/<slug>/ following the standard
npm run sync && npm run emit
npm run check     # validate + generators current + the gates still fail on bad input
# open a PR

Hardware must be CERN-OHL-S-2.0 and code MIT, and the pack must include a Hangar Bay template. A community body gets a known template — pick it by name in Hangar Bay, flash, go — once it is accepted into the catalog. Until then it uses Hangar Bay's builder, which can already build whatever you design.

Meckie bodies are open hardware (CERN-OHL-S-2.0) and open code (MIT). Meckie OS is free to download; the Meckie brain is a paid service. A body flashes and runs its reflexes without an account — it needs one to think and talk.
